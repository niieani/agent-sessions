# Rust

The workload requires streaming large JSONL files, read-only SQLite extraction, token counting and SSH collection. Rust provides bounded memory, explicit read-only database access and standalone binaries for deployment without a language runtime.

## Considered options

- **TypeScript** — requires a runtime on each collection Host and careful handling of memory during large-file parsing.
- **Go** — suitable for distribution; Rust better fits the selected parsing and tokenizer libraries.
