# Hosted Sources have no Origin Host

Status: accepted. The confirmed-Origin-Host display policy is reaffirmed by [the promotion golden decision](2026-10-21-promotion-goldens-preserve-origin-and-media.md).

Status: accepted

A Hosted Source (ChatGPT) runs its Sessions on a remote service; the Host that captured them, such as the Mac running the browser, contributed evidence but originated nothing. Views therefore present only an Origin Host, and an empty one when none is evidenced or the Source is hosted. The earlier fallback that showed the Projection winner's Host, then the first contributing Host, is removed: it presented a capturing machine as the place a conversation happened. Contributing Hosts remain in Provenance and Capture sidecars, and Host Attribution and Host Preferences still apply to Sources that run on Hosts.
