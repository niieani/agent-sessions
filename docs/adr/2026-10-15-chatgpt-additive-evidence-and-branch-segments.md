# ChatGPT Captures accumulate evidence; Branch Segments use shared Views

Status: accepted

ChatGPT exports contain complete parent-linked graphs, while the website supplies selected-path pages and separate Versions responses. Replacing an exported Capture with one newer partial page would destroy recoverable history. Keep additive native evidence records inside the existing per-Session compressed Capture, with exact payload bytes recoverable from each record. Rebuild uses one Adapter and the ordinary canonical Session identity. The disposable database retains all canonical Branch Segments per Host and selects them using its existing Projection winner. Search and Digest retain a selected-path Message projection.

Branches are alternate continuations, not Subagents or separate Sessions. Reusing Subagent identity would incorrectly imply delegation and reclassify user Messages as Parent Instructions. Extraction partitions native graphs into source-neutral maximal nonbranching dialogue segments. Shared Units, templates and layout planning render them, preserving `<user>` roles and adding links between continuation files rather than native Message anchors. Graph-only internal segments are coalesced. Workday attribution includes ancestor turn context but renders each Message once. Stable branch-identity suffixes distinguish continuation paths; all references use the final collision-resolved filenames.

Adapters interpret native content and provide typed disposable Render Assets; the shared renderer writes those artifacts and rebases only registered generated references for the actual Transcript directory. This keeps native format knowledge in the Adapter without duplicating Transcript policy. Rich presentation, layout and branch navigation can evolve independently. A Source's captured native name can be chosen explicitly through the generic `native_title` layout variable without manufacturing model-written Digests or Locked Titles.

Costs: additive evidence requires per-conversation re-extraction, and canonical branch structure expands the shared View contract. Native browser arrays cannot reconstruct omitted internal Action nodes; their visible order is preserved, while complete response evidence remains available for future extraction. A source payload that changes representation does not erase an earlier payload. Existing linear Sources keep empty branch projections and their unchanged shared rendering behavior.
